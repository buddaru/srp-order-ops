Key Data Flows
📦 Order Created by Staff Staff fills OrderModal → optimistic update → supabase INSERT → Realtime broadcast → all browsers update
📧 Bento Order Sync Bento → Gmail → Header triggers sync-orders.js → parse email HTML → INSERT orders → Realtime push
📱 SMS Notification Staff clicks SMS on Drawer → POST /api/send-sms → Twilio → customer phone · log notification to order
🧾 Invoice AI Pipeline Upload PDF → parse-invoice (Claude) → confirm line items → apply-invoice → update ingredient prices
👤 Auth + Location Load Login → AuthContext loads session + memberships → LocationContext resolves slug → BusinessContext loads settings
🍽️ Recipe Sync (Meez) Staff triggers → Header → POST /api/sync-meez → Meez API chunks → upsert recipes in Supabase
